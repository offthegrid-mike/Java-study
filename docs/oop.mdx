# OOP Principles

Object-oriented programming rests on four pillars: **encapsulation**,
**inheritance**, **polymorphism**, and **abstraction**.

## Encapsulation

Hide internal state behind methods. Make fields `private` and expose controlled
access through getters/setters, so the object enforces its own invariants.

## Inheritance (`extends`)

A subclass `extends` a superclass to reuse and specialize behavior. A `Dog`
**is-a** `Animal`. Java supports single class inheritance (one direct
superclass), but a class can implement many interfaces.

## Polymorphism: overriding vs overloading

- **Overriding** (runtime polymorphism): a subclass redefines an inherited
  method with the same signature. The actual method called is decided at runtime
  by the object's real type.
- **Overloading** (compile-time): multiple methods share a name but differ in
  parameter lists. The compiler picks one based on the arguments.

## Abstraction

Expose *what* an object does, not *how*. Achieved with abstract classes and
interfaces that declare behavior without (full) implementation.

## Interface vs abstract class

| | Abstract class | Interface |
| --- | --- | --- |
| State (fields) | Yes | Only constants (default behavior via `default` methods) |
| Multiple inheritance | No (one superclass) | Yes (implement many) |
| Constructors | Yes | No |
| Use when | Sharing code + state among closely related classes | Defining a capability/contract many unrelated types can adopt |

Run an inheritance + override example:

<RunnableJava code={`public class Main {
  static class Animal {
    String speak() { return "..."; }
  }

  static class Dog extends Animal {
    @Override
    String speak() { return "Woof"; }   // overriding
  }

  static class Cat extends Animal {
    @Override
    String speak() { return "Meow"; }   // overriding
  }

  public static void main(String[] args) {
    // Polymorphism: the superclass reference, the subclass behavior
    Animal[] animals = { new Dog(), new Cat(), new Animal() };
    for (Animal a : animals) {
      System.out.println(a.speak());   // resolved at runtime by real type
    }
  }
}`} />
