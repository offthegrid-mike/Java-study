# Classes & Objects

A **class** is a blueprint; an **object** is a concrete instance created from it
with `new`. A class bundles state (fields) and behavior (methods) together.

## Class anatomy

```java
public class Account {
    private double balance;          // field (state)

    public Account(double opening) { // constructor
        this.balance = opening;      // 'this' disambiguates field vs parameter
    }

    public void deposit(double amt) { // instance method (behavior)
        this.balance += amt;
    }

    public double getBalance() {
        return balance;
    }
}
```

## Creating objects with `new`

`new Account(100)` allocates the object on the heap, runs the constructor, and
returns a reference. The constructor initializes the object's state.

## `this`

`this` is a reference to the current object. It is most often used to
distinguish a field from a parameter of the same name, or to call another
constructor in the same class.

## `static` vs instance members

- **Instance members** belong to each object — every object has its own copy.
- **`static` members** belong to the class itself; they are shared across all
  instances and accessed via the class name (e.g. `Math.PI`).

## Access modifiers

| Modifier | Visible to |
| --- | --- |
| `public` | everyone |
| `protected` | same package + subclasses |
| (default / package-private) | same package only |
| `private` | the declaring class only |

Run a small class with a constructor and a method:

<RunnableJava code={`class Main {
  // A nested helper class with a constructor and a method
  static class Account {
    private double balance;          // private field

    Account(double opening) {        // constructor
      this.balance = opening;        // 'this' refers to the new object
    }

    void deposit(double amt) {       // instance method
      this.balance += amt;
    }

    double getBalance() {
      return balance;
    }
  }

  public static void main(String[] args) {
    Account a = new Account(100.0);  // object creation with new
    a.deposit(50.0);
    System.out.println("Balance: " + a.getBalance());
  }
}`} />
