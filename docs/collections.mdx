# Collections Framework

The Collections Framework provides reusable data structures behind a small set of
interfaces. The big three are `List`, `Set`, and `Map`.

## Core interfaces

- **`List`** — ordered, allows duplicates, index access (`ArrayList`, `LinkedList`).
- **`Set`** — no duplicates (`HashSet`, `TreeSet`, `LinkedHashSet`).
- **`Map`** — key/value pairs, unique keys (`HashMap`, `TreeMap`, `LinkedHashMap`).

(`Map` is technically not a `Collection`, but it is part of the framework.)

## `ArrayList` vs `LinkedList`

- `ArrayList` is backed by a resizable array: O(1) random access by index, but
  inserting/removing in the middle is O(n) due to shifting.
- `LinkedList` is a doubly linked list: O(1) insert/remove at the ends (and at a
  known node), but O(n) random access. In practice `ArrayList` wins for most
  workloads.

## `HashMap` vs `TreeMap`

- `HashMap` — average O(1) `get`/`put`, **no ordering**, allows one `null` key.
  Relies on `hashCode`/`equals`.
- `TreeMap` — a red-black tree, keeps keys **sorted**, with O(log n) operations.

## `HashSet`

A `HashSet` is backed by a `HashMap`: average O(1) `add`/`contains`/`remove`, no
ordering, no duplicates. Use `TreeSet` when you need sorted iteration.

## Rough Big-O cheat sheet

| Operation | `ArrayList` | `LinkedList` | `HashMap` | `TreeMap` |
| --- | --- | --- | --- | --- |
| get by index/key | O(1) | O(n) | O(1) avg | O(log n) |
| add at end / put | O(1) amortized | O(1) | O(1) avg | O(log n) |
| remove (middle/key) | O(n) | O(1) at known node | O(1) avg | O(log n) |

**When to pick:** use `ArrayList` by default; `LinkedList` only for heavy
end-queue use; `HashMap`/`HashSet` for fast lookups without ordering;
`TreeMap`/`TreeSet` when you need sorted order.

Run a `List` and a `Map` example:

<RunnableJava code={`import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class Main {
  public static void main(String[] args) {
    List<String> names = new ArrayList<>();
    names.add("Ada");
    names.add("Linus");
    names.add("Grace");
    for (String n : names) {
      System.out.println("name: " + n);
    }

    Map<String, Integer> ages = new HashMap<>();
    ages.put("Ada", 36);
    ages.put("Grace", 85);
    for (Map.Entry<String, Integer> e : ages.entrySet()) {
      System.out.println(e.getKey() + " -> " + e.getValue());
    }
  }
}`} />
