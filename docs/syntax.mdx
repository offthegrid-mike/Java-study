# Java Basics & Syntax

Every Java program lives in a class. Code is compiled (`javac`) into bytecode
(`.class`), which the JVM runs — this "write once, run anywhere" step is a
favorite interview opener.

## A minimal program

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## Variables, operators, control flow

```java
int count = 3;                 // declaration + assignment
boolean even = count % 2 == 0; // operators
if (even) { System.out.println("even"); }
for (int i = 0; i < count; i++) { System.out.println(i); }
```
