# Data Types

Java is statically typed. Every variable has a type known at compile time, and
types split into two families: **primitives** (raw values) and **references**
(pointers to objects on the heap).

## The 8 primitive types

| Type | Size | Range / notes |
| --- | --- | --- |
| `byte` | 8-bit | -128 to 127 |
| `short` | 16-bit | -32,768 to 32,767 |
| `int` | 32-bit | the default integer type |
| `long` | 64-bit | suffix `L`, e.g. `100L` |
| `float` | 32-bit | suffix `f`, e.g. `3.14f` |
| `double` | 64-bit | the default floating type |
| `char` | 16-bit | a single UTF-16 unit, e.g. `'A'` |
| `boolean` | JVM-dependent | `true` or `false` only |

## Reference vs primitive

A primitive variable holds the value directly. A reference variable holds the
address of an object (or `null`). Comparing primitives with `==` compares values;
comparing references with `==` compares identity, not content.

## Wrapper classes, autoboxing, and unboxing

Each primitive has a wrapper class: `int`/`Integer`, `double`/`Double`,
`boolean`/`Boolean`, etc. Wrappers are objects, so they can live in collections
and be `null`. **Autoboxing** converts a primitive to its wrapper automatically;
**unboxing** does the reverse.

## String immutability and the String pool

`String` objects are immutable — every "modification" creates a new object. The
JVM keeps a **String pool** so identical string literals share one instance,
saving memory. This immutability is what makes Strings safe as map keys and
thread-safe.

## Widening vs narrowing

Assigning a smaller type to a larger one (`int` → `double`) is **widening** and
happens implicitly. Going the other way (`double` → `int`) is **narrowing** and
requires an explicit cast, which can lose data.

```java
int i = 7;
double d = i;        // widening, automatic
int back = (int) d;  // narrowing, explicit cast required
```

Run autoboxing plus widening:

<RunnableJava code={`public class Main {
  public static void main(String[] args) {
    // Autoboxing: primitive int -> Integer wrapper
    Integer boxed = 42;        // autoboxed
    int unboxed = boxed;       // unboxed
    System.out.println("Boxed=" + boxed + ", unboxed=" + unboxed);

    // Widening: int promoted to double in the expression
    int count = 5;
    double avg = count / 2.0;  // int widened to double
    System.out.println("avg=" + avg);

    // Narrowing requires an explicit cast
    double pi = 3.99;
    int truncated = (int) pi;  // loses the fraction
    System.out.println("truncated=" + truncated);
  }
}`} />
