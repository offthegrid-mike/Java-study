# Memory & Garbage Collection

Java manages memory for you. The garbage collector (GC) automatically reclaims
objects that are no longer reachable, so you rarely free memory by hand.

## Stack vs heap

- **Stack** — per-thread; holds method frames, local variables, and references.
  Fast, LIFO, automatically reclaimed when a method returns.
- **Heap** — shared across threads; holds all objects (and their instance
  fields). This is where the GC operates.

## Reachability and GC roots

An object is **eligible for collection** when it is no longer reachable from any
**GC root** — roots include local variables on the stack, active threads, static
fields, and JNI references. If nothing can reach an object, it can be collected.

## Generational GC

Most objects die young, so the heap is split into generations:

- **Young generation** (Eden + two survivor spaces) — new objects. A
  **minor GC** collects the young gen frequently and cheaply.
- **Old (tenured) generation** — objects that survived several minor GCs get
  promoted here. A **major GC** (or full GC) collects the old gen and is more
  expensive.

## Common collectors (one-liners)

- **Serial** — single-threaded; good for small heaps / single-CPU.
- **Parallel** — multi-threaded throughput collector.
- **G1** — the modern default; divides the heap into regions and aims for
  predictable pause times.

## Reference strength

- **Strong** — the normal reference; never collected while reachable.
- **Soft** (`SoftReference`) — collected only when memory is low; good for caches.
- **Weak** (`WeakReference`) — collected at the next GC if only weakly reachable;
  used by `WeakHashMap`.
- **Phantom** (`PhantomReference`) — enqueued after finalization; used for
  precise post-mortem cleanup.

> Note: `System.gc()` is only a **hint** to the JVM. The JVM may ignore it and
> decide when (or whether) to actually run a collection.

Run a small program that drops a reference and hints at GC:

<RunnableJava code={`class Main {
  static class Resource {
    final String name;
    Resource(String name) { this.name = name; }
  }

  public static void main(String[] args) {
    Resource r = new Resource("temp");
    System.out.println("created: " + r.name);

    r = null;            // the object is now unreachable -> eligible for GC
    System.gc();         // only a HINT; the JVM may or may not collect now

    Resource keep = new Resource("kept");
    System.out.println("still reachable: " + keep.name);
  }
}`} />
