# How to Use This Site

This guide covers the Java concepts most likely to appear in a mid-level interview.
Each topic page has four parts:

- **Explanation** — the concept in plain language.
- **Runnable examples** — edit the code and press **Run** to execute real Java in your browser.
- **Flashcards** — flip through key facts and mark the ones you know.
- **Quiz** — check your understanding; score 80%+ to mark it passed.

The **Interview Q&A** page collects common questions with a "Mastered" checkbox.
Your flashcard, quiz, and Q&A progress is saved in your browser — see the
[My Progress](/progress) page for a summary.

> Progress is stored locally (localStorage). Clearing your browser data resets it.
